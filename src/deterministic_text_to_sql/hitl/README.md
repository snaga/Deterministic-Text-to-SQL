# `hitl` サブパッケージ仕様 (L1 Intent)

本ドキュメントは、`deterministic_text_to_sql.hitl` パッケージの設計意図、モジュール境界、Human-in-the-Loop (HITL) の意義、および依存制約を永続化するための仕様書（L1 Intent）です。

---

## 1. 概要と責務

`hitl` パッケージは、自然言語クエリから単一の集計意図を一意に特定できない競合状態（例: 売上の定義が明細行ベースなのか注文伝票ベースなのか）を検知し、ユーザーに対する安全な確認要求（`HITLIssue`）の発行およびスラッシュ構文（`/ Aで` 等）によるコンテキスト再合成を担う対話管理モジュールです。

### 責務 (What it does)
- **スラッシュ補足構文のパース (`feedback.py:parse_input`)**: 入力末尾の `/ Aで` や `--clarify A` をパースし、ベースクエリと追加指定を決定論的に分離。
- **曖昧性の検知 & 介入要求生成 (`feedback.py:check_ambiguity`)**: Jev API のスロット判定や確率拮抗から曖昧性を検出し、明確な選択肢（`HITLOption`）を持つ `HITLIssue` を生成。
- **自然言語ステートのコンテキスト合成 (`feedback.py:synthesize_eval_state`)**: ユーザーの補足選択（例: `A` や `明細`）を自然言語クエリに適切に追記し、Jev API 再投入用ステートを構築。
- **機械可読サマリー生成 (`feedback.py:format_hitl_summary`)**: CLI および AI エージェント（`--json` モード）向けに、確定スロット（テーブル、軸、指標、フィルタ）の構造化辞書を生成。
- **データモデル定義 (`models.py`)**: `HITLOption`, `HITLIssue`, `ParsedQueryInput` の不変モデル（`frozen=True`）化。

### 扱わないこと (What it does NOT do)
- CLI ターミナル描画やインタラクティブループ（`cli.py` の責務）。
- Jev API との直接通信（`jev.client` の責務）。
- AST の直接組み立てや SQL 出力（`compiler` の責務）。
- スキーマ間の結合パス探索（`graph` の責務）。

---

## 2. HITL (Human-in-the-Loop) の意義と原則

### 1. 勝手な推測（ハルシネーション）の完全防止
LLM ベースの Text-to-SQL では、分析者が意図した売上が「明細売上（lineitem: 値引きや明細数量）」なのか「伝票売上（orders: 注文確定総額）」なのかが曖昧な場合、確率的に片方を勝手に選んで誤った数値を生成してしまうリスクがあります。
本エンジンは決定論的 Text-to-SQL を標榜しており、確信度が拮抗している場合は**推測による自動実行を停止し、人間に明示的に確認する**ことを最優先原則とします。

### 2. 最小の手数で曖昧性を解消するスラッシュ構文
ユーザーが曖昧性の確認に対して最初からクエリ全体を打ち直す手間を削減するため、クエリ末尾に `/ A` または `/ B` を付与するだけで再実行できるスラッシュ構文パーサーを提供します。

```text
# 初回実行（曖昧性検知 -> HITL介入要求コード2返却）
$ deterministic-text-to-sql "アジアの顧客の売上トップ5"
-> 選択肢 A: lineitem (商品明細売上)
-> 選択肢 B: orders (注文伝票売上)

# 最短での再実行（スラッシュ構文）
$ deterministic-text-to-sql "アジアの顧客の売上トップ5 / Aで"
-> 決定論的 SQL 生成完了
```

## 3. 依存制約ルール (Dependency Rules)

1. **上位・下位の依存方向**:
   - `hitl` は `jev.models`（`ParsedSlots` 等）を参照しますが、上位の `engine.py` や `cli.py` に依存してはなりません。
   - `compiler`, `graph`, `schema` に対しても不要な直接依存を行わず、スロット情報に基づいて動作します。
2. **決定論的かつ純粋なデータ処理**:
   - `HITLManager` の各メソッドは I/O や副作用を一切持たず、純粋関数として設計されています。
