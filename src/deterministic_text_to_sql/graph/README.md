# Graph サブパッケージ (L1 Intent)

## 責務 (Responsibility)
テーブル間の外部キー（FK）参照関係をグラフ構造としてモデル化し、主テーブルから複数ターゲットテーブルへの最短結合パス（Dijkstra法）の探索およびSQL ON句条件の自動解決を行います。

## 含まれる主要コンポーネント
- `JoinStep`: 単一のテーブル結合ステップ（結合元テーブル、結合先テーブル、カラム対応ペア、ON句文字列）を表現するイミュータブルモデル
- `SchemaGraph`: `networkx.Graph` を内部に保持し、無向エッジとしてFKリレーションを構築・最短パス探索と結合木のマージを行うリゾルバー
- `GraphError` / `UnconnectedSchemaError`: グラフ探索・結合解決時の例外

## 依存制約 (Dependency Rules)
- **許可される依存先**: 標準ライブラリ (`typing`), `networkx`, `pydantic`, `deterministic_text_to_sql.schema`
- **禁止される依存先**: 上位レイヤー (`compiler`, `jev`, `hitl`, `engine`, `cli`) への逆依存

## 技術選定理由 (Why NetworkX?)
1. **決定論的かつ高速な探索 (<1ms)**:
   外部キー参照関係をグラフ理論上の無向グラフとしてモデル化することで、ダイクストラ法（`nx.shortest_path`）により最短ホップ数の結合パスをミリ秒未満で決定論的に算出できます。
2. **ハルシネーションの排除**:
   LLMにテーブル結合を推測させず、定義された外部キー制約のみからパスを幾何学的に特定するため、存在しない結合や直積（Cartesian Product）の誤生成を原理的に防止します。
3. **複合外部キーおよび双方向結合の透過的サポート**:
   参照元から参照先への結合だけでなく、逆方向（被参照テーブルから参照元テーブル）への結合や複数カラムによる複合キー結合を透過的に解決します。
